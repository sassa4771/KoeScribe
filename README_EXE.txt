========================================
KoeScribe GUI - 使用方法（EXE版）
========================================

このファイルは、exe形式で配布されたKoeScribe GUIの簡易使用説明書です。

【起動方法】
1. KoeScribe-GUI.exe をダブルクリックして起動します

【基本的な使い方】
1. 「ファイル追加」または「フォルダ追加」ボタンで音声・動画ファイルを選択
2. 必要に応じて設定を調整（モデルサイズ、話者数など）
3. 「処理開始」ボタンをクリック
4. 処理完了後、結果テーブルから出力ディレクトリにアクセス

【対応ファイル形式】
- 音声: WAV, MP3, M4A, FLAC, OGG, AAC
- 動画: MP4, MKV, AVI, MOV, FLV, WMV, WebM, M4V, MPG, MPEG

【話者分離機能について】
話者分離機能はオプションです。使用しない場合は設定不要です。

■ 話者分離機能を使用しない場合
→ .envファイルは不要です。GUIの「話者分離」チェックボックスをOFFにしてください。

■ 話者分離機能を使用する場合

【重要】初回ダウンロード時のみトークンが必要です
- 一度ダウンロードすれば、ローカルキャッシュ（ユーザーのホームディレクトリ）に保存されます
- 次回以降は、トークンなしで使用できます

【初回設定手順】
1. このexeファイルと同じディレクトリに .env ファイルを作成
2. .env ファイルに以下の内容を記述:
   HUGGINGFACE_TOKEN=hf_your_token_here
3. Hugging Face (https://huggingface.co) でトークンを取得してください
   - アカウント作成後、[Settings > Access Tokens] でトークンを生成
   - [pyannote/speaker-diarization] の利用規約に同意が必要です
4. GUIの「話者分離」チェックボックスをONにしてください
5. 初回実行時にモデルがダウンロードされます（数分かかる場合があります）

【2回目以降】
- .envファイルは削除しても構いません（ローカルキャッシュから読み込みます）
- ただし、以下の場合は再度トークンが必要です:
  * 別のPCで使用する場合
  * 同じPCでも別のユーザーアカウントで使用する場合
  * ローカルキャッシュを削除した場合

【複数ユーザーで使用する場合】
- モデルは各ユーザーのホームディレクトリに保存されます
- ユーザーAがダウンロードしても、ユーザーBは別途ダウンロードが必要です
- 各ユーザーが初回のみトークンを設定する必要があります

【初回実行時の注意】

■ Whisperモデル（文字起こし用）
- 初回実行時、Whisperモデルが自動的にダウンロードされます
- ダウンロード先: ユーザーのホームディレクトリ（例: C:\Users\ユーザー名\.cache\huggingface\）
- インターネット接続が必要です
- モデルサイズによっては数GBの容量が必要です
- ダウンロードには時間がかかる場合があります

■ 話者分離モデル（話者分離機能を使用する場合）
- 初回実行時、話者分離モデルが自動的にダウンロードされます
- ダウンロード先: ユーザーのホームディレクトリ（例: C:\Users\ユーザー名\.cache\huggingface\）
- 初回ダウンロード時のみ、.envファイルにHUGGINGFACE_TOKENが必要です
- 一度ダウンロードすれば、次回以降はトークン不要です

【トラブルシューティング】
- アプリが起動しない場合:
  → コマンドプロンプトから実行してエラーメッセージを確認
  → ウイルス対策ソフトがブロックしていないか確認

- モデルがダウンロードされない場合:
  → インターネット接続を確認
  → ファイアウォールの設定を確認

- 話者分離が動作しない場合:
  【初回ダウンロード時】
  → .env ファイルが正しい位置（exeと同じディレクトリ）にあるか確認
  → トークンが正しく設定されているか確認（HUGGINGFACE_TOKEN=hf_...）
  → Hugging Face のアカウントで利用規約に同意しているか確認
  
  【2回目以降】
  → ローカルキャッシュ（~/.cache/huggingface/）にモデルがダウンロードされているか確認
  → 初回ダウンロード時にトークンを使用してモデルをダウンロードしていれば、トークンなしで動作します
